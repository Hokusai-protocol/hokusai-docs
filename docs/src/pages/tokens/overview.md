# Token Overview

Learn about the different types of tokens in the Hokusai Protocol and how they work together.

## Token Types

1. **DeltaOne Tokens**: Represent model performance
2. **Data Tokens**: Reward data contribution
3. **Governance Tokens**: Enable protocol participation

## Token Creation

- **Model Tokens**: Created by AI developers
- **Data Tokens**: Generated through data contribution
- **Governance Tokens**: Distributed through protocol participation

## Token Utility

- **Trading**: Buy and sell tokens on DEXs
- **Staking**: Earn rewards by staking tokens
- **Governance**: Participate in protocol decisions
- **Access**: Use tokens to access premium features
