# Tokenomics

The Hokusai Protocol's tokenomics are designed to create sustainable incentives for both data suppliers and AI developers.

## Token Distribution

- **Data Suppliers**: 60% of tokens allocated for data contribution rewards
- **AI Developers**: 30% of tokens for model performance and development
- **Protocol Treasury**: 10% reserved for protocol development and governance

## Reward Mechanisms

1. **Data Quality**: Higher quality data receives more tokens
2. **Model Performance**: Better performing models earn more tokens
3. **Long-term Holding**: Staking rewards for token holders
4. **Governance**: Token holders can participate in protocol decisions

## Economic Model

- **Supply**: Controlled token emission based on protocol activity
- **Demand**: Driven by model performance and data quality
- **Value**: Tied to the quality and utility of AI models
- **Sustainability**: Long-term incentives for all participants
