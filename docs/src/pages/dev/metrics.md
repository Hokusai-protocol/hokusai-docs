# Metrics

Learn about the key metrics and analytics available in the Hokusai Protocol.

## Model Metrics

### Performance Metrics

- **Accuracy**: Model prediction accuracy
- **Latency**: Response time for inference
- **Throughput**: Requests processed per second
- **Error Rate**: Percentage of failed requests

### Usage Metrics

- **Active Users**: Number of unique users
- **Request Volume**: Total number of requests
- **Token Distribution**: Token allocation across users
- **Data Contribution**: Volume of data submitted

## Data Metrics

### Quality Metrics

- **Data Quality Score**: Overall quality assessment
- **Validation Rate**: Percentage of validated data
- **Rejection Rate**: Percentage of rejected submissions
- **Contribution Value**: Value of contributed data

### Contribution Metrics

- **Active Contributors**: Number of data suppliers
- **Submission Volume**: Total data submissions
- **Reward Distribution**: Token rewards per contributor
- **Quality Distribution**: Distribution of data quality scores

## Token Metrics

### Economic Metrics

- **Token Price**: Current market price
- **Trading Volume**: 24-hour trading volume
- **Market Cap**: Total token value
- **Circulating Supply**: Available tokens

### Staking Metrics

- **Total Staked**: Amount of staked tokens
- **Staking APY**: Annual percentage yield
- **Staking Duration**: Average staking period
- **Reward Distribution**: Staking rewards per period
