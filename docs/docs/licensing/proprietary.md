# Proprietary License

## Overview

Proprietary models are owned by a single owner. This is typically companies that have a model they want to improve. They want to reward data suppliers for helping them improve their models, but do not want to share access to the model or any details about how it works with anyone else. 

## Key License Features

- One entity has exclusive usage of the model.  
- There is no AMM trading or API revenue generation. The DeltaOne reward payable to data suppliers for their contribution is funded directly by the model owner and is the sole compensation. 
- Data suppliers will have no ongoing relationship with the model owner. 

## DeltaOne Reward Mechanism 

- Proprietary models have no usage that will contribute to the DeltaOne Reward, so the model owner is responsible for funding these rewards. 
- Model owners deposit funds into the model rewards pool to create incentives.
