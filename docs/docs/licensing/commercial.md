# Commercial License

## Overview

Commercial models are the core Hokusai offering, representing an individual market for the underlying AI model. These models are available to anyone willing to pay for them. Data suppliers can elect to receive long-term ownership stakes in the model or cash. 

## Key License Features

- The usage of this model is available to anyone willing to meet the commercial terms. An API will be available and usage can be purchased. 
- API payments fund rewards to data suppliers. A portion of the API payment is used to purchase tokens from the marketplace, reducing the supply of the token, and making it more attractive as a reward for data suppliers.  
- Data suppliers receive tokens for their data contributions. This increases the supply of the token based on their improvement of the model
- Tokens represent an ownership stake in the underlying model. They can be converted to USDC or held for short- or long-term ownership. 
- Holders of the underlying token make decisions about how to price and provision the model. 

## DeltaOne Reward Mechanism 

- Commercial models derive their value from ongoing API usage. API fees flow to the AMM's USDC reserve pool, increasing the reserve backing per token and supporting token value.
- Investors can participate during the seven-day launch period to provide initial liquidity and support early data suppliers.
