# Token Bonding

Learn about the bonding curve mechanism in the Hokusai Protocol.

## Bonding Curves

### Curve Types

- **Linear**: Linear price increase
- **Exponential**: Accelerating price increase
- **Polynomial**: Custom price curves
- **Hybrid**: Combined curve types

### Parameters

- **Initial Price**: Starting token price
- **Curve Slope**: Rate of price increase
- **Supply Cap**: Maximum token supply
- **Reserve Ratio**: Reserve token ratio

## Bonding Mechanics

### Buying Tokens

1. **Calculate Price**: Determine current price
2. **Provide Liquidity**: Add to bonding pool
3. **Receive Tokens**: Get minted tokens
4. **Update Curve**: Adjust price curve

### Selling Tokens

1. **Calculate Value**: Determine token value
2. **Burn Tokens**: Remove from supply
3. **Receive Value**: Get reserve tokens
4. **Update Curve**: Adjust price curve

## Applications

### Use Cases

- **Token Launch**: Initial token distribution
- **Price Discovery**: Market price finding
- **Liquidity Provision**: Continuous liquidity
- **Value Accrual**: Long-term value growth

### Benefits

- **Price Stability**: Reduced volatility
- **Continuous Liquidity**: Always available
- **Fair Distribution**: Equal access
- **Value Alignment**: Long-term incentives
