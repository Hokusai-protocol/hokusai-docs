# Tokenomics Overview

Hokusai's tokenomics are designed to create a sustainable ecosystem that rewards data contributors while maintaining the value of the protocol's tokens.

## Core Components

### 1. Token Value
- Performance-based minting
- API fee revenue to AMM reserves
- Supply dynamics
- Price discovery via CRR bonding curve

[Learn more about Token Value](/tokenomics/token-value)

### 2. Bonding Curve
- Price discovery mechanism
- Liquidity management
- Supply controls
- Market dynamics

[Learn more about Bonding Curve](/tokenomics/bonding-curve)

### 3. DeltaOne Calculations
- Performance measurement
- Reward distribution
- Verification process
- Value assessment

[Learn more about DeltaOne Calculations](/tokenomics/deltaone-calculations)

## Key Concepts

### Token Utility
- Model access rights
- Governance participation
- Reward distribution
- Value accrual

### Economic Model
- API fees increase token reserve backing
- Performance-based minting
- CRR bonding curve pricing
- Governance controls
