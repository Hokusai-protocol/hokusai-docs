# Open Source License

## Overview

Open source model are freely available to use, study, modify, and share, promoting a collaborative and transparent approach to AI development. Hokusai provides support for open source models and uses a donation model to create financial incentives for data suppliers who would otherwise not contribute data. 

## Key License Features

- Freely available for usage, reuse, for any purpose.  
- There is no token buyback or proprietary owner - open source models rely on donations to create incentives. 
- The DeltaOne reward payable to data suppliers for their contribution is the sole compensation. 
- Data suppliers should evaluate whether they would contribute their data to the model for free. Donors are hard to come by! 

## DeltaOne Reward Mechanism 

- Open Source models have no usage that will contribute to the DeltaOne Reward. The only mechanism for providing incentives is through donations. 
- Donors deposit funds into the model rewards pool to create incentives. Verified open source
- There is no token ownership or reward for donating to an open source model, other than the recognition that you are supporting a more open AI & data ecosystem.
