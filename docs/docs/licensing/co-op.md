# Co-op License

## Overview

Co-op models are proprietary models that are shared by a whitelisted group of users. This model is best for groups of customers that are in a similar field and wish to collaborate and reward data contributions with proportional usage and ownership rights. These customers are often data suppliers themselves, though they can also elect to fund a rewards pool to incentivize data suppliers. 

## Key License Features

- The usage of this model is available to a list of pre-approved users. Only those users can access the model. 
- Access is shared amongst the whitelisted users. Generally this is by ownership but can be customized.   
- Tokens represent an ownership stake in the underlying model. They can be used for long-term access or converted to cash. 
- Holders of the underlying token make decisions about how to provision the model and how / whether to fund a rewards pool. 

## DeltaOne Reward Mechanism 

- Data suppliers on the whitelist receive tokens for their data contributions. Those not on the whitelist receive USDC. 
- Co-op models have no usage that will increase the DeltaOne Reward, so the model owner is responsible for funding any reward pool.
