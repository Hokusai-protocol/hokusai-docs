To begin with Hokusai:

1. **For Data Suppliers**:
   - Review data submission guidelines.
   - Use the SDK to test and format your data.
   - Submit data for evaluation.

2. **For AI Model Developers**:
   - Integrate your model with the Hokusai SDK.
   - Define performance metrics for DeltaOne token issuance.
   - Monitor model performance and token distribution.

3. **For Token Investors**:
   - Understand the bonding curve mechanism.
   - Participate in token auctions.
   - Monitor token supply and burn rates.

Proceed to the relevant sections for detailed instructions.
