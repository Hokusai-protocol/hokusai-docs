# Data Suppliers

Data suppliers play a crucial role in enhancing AI models within the Hokusai ecosystem.

**Process:**

1. **Data Preparation**:
   - Ensure data is anonymized and complies with privacy standards.
   - Format data according to the protocol's specifications.

2. **Testing**:
   - Utilize the Hokusai SDK to test data compatibility and potential impact.

3. **Submission**:
   - Submit data through the protocol's interface for evaluation.

4. **Evaluation**:
   - Data is assessed for its contribution to model performance.
   - Successful contributions leading to performance improvements result in DeltaOne token rewards.

Refer to the subsequent sections for detailed guidelines and tools.
