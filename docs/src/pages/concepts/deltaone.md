# DeltaOne Tokens

DeltaOne tokens are the core innovation of the Hokusai Protocol. They represent the performance of AI models and enable a new way to incentivize and reward data contribution.

## What are DeltaOne Tokens?

DeltaOne tokens are ERC-20 tokens that:

- Track the performance of AI models
- Enable data suppliers to earn rewards
- Create a market for model performance

## How They Work

1. **Token Creation**: AI developers create tokens for their models
2. **Performance Tracking**: Model performance is measured and reflected in token value
3. **Data Rewards**: Data suppliers earn tokens based on their contributions
4. **Market Trading**: Tokens can be traded on decentralized exchanges

## Benefits

- **Fair Incentives**: Direct correlation between data quality and rewards
- **Market Efficiency**: Price discovery for model performance
- **Transparency**: Clear metrics for model quality
- **Sustainability**: Long-term incentives for data contribution
